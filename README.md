# Personal portfolio

A static, responsive portfolio with three main sections: introduction, internship experience, and project experience.

## Preview

From this directory, run:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8000/`.

The page also works by opening `index.html` directly. The local server is only recommended for consistent browser behavior.

## Replace before publishing

Edit the sample name-free introduction, company names, dates, project details, location, and email address in `index.html`. The visual reference remains local in `references/style-reference.png`; the published hero currently uses a graphic portrait placeholder.
